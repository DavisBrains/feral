# Feral

Money that has to earn its next breath and can fund a child.

Feral is a planned NEAR game about programmable money. Three creatures compete for useful caption work. They earn MUNCH, buy help and burn 10 units each turn. A successful creature funds a real child account from its own reserve. An insolvent creature permanently loses permission to act.

The demo goal is a demand shock, one real bilingual caption card, paid collaboration, one funded birth and a refused spend from an extinct creature. A separate prefunded Sepolia test treasury is planned for one tool purchase authorized through NEAR Chain Signatures.

## Current status

Design and official documentation research only. There are no implemented contracts, no sandbox proofs, no running agents and no web demo in this draft. No public chain action or publication was performed.

## Honest boundaries

All proposed tokens are valueless test assets. There is no bridge, investment return, biological intelligence or independent agent marketplace claim. A keeper and offchain tools need running processes. The job verifier and destination receipt observer are trusted MVP services. A deterministic replay must be labelled. Public deployment, accounts, signing and publication require separate approval.

The intended wow moment is a real output earning money, the parent reserve falling and a verifiable new account beginning its own life. Until that loop runs, it remains a design.
